# Theme engine gap audit (read-only)

Date: 2026-09-29. Scope: `reactnative-mobile/` theme engine, audited against the contract in the task and `docs/theme-customization-plan.md` §0, §7, §9, §10. No source file was changed.

Paths below are relative to `reactnative-mobile/src/` unless they start with `reactnative-mobile/` or `docs/`.

## Summary

| Result | Count |
| --- | --- |
| PASS | 7 |
| FAIL | 3 |
| UNVERIFIED | 1 |

Three most important FAILs:

1. **No Undo snackbar (item 4).** Nothing in `src/` renders a snackbar or uses an 8 s timer (search for `snackbar|Snackbar|8000` has no hits). Undo exists only as a header icon inside the Appearance screen (`screens/appearance/appearance-screen.tsx:182-193`, `:276-285`). `undoLastApply` also swaps current and previous (`theme/theme-preference.tsx:273-278`), so pressing Undo a second time re-applies the undone settings (it acts as Redo).
2. **No selective subscriptions; the whole tree re-renders on every animation frame (item 7).** The color cross-fade calls `setColors` from an `Animated` listener on every frame (`theme/theme-preference.tsx:329-331`). The legacy context that about 100 files use bundles colors and typography together (`theme/theme-preference.tsx:401-404`). The split hooks `useColors` / `useTypography` / `useLayoutTokens` are called only in `screens/appearance/appearance-preview.tsx` (count: 3 call sites outside the theme folder). Plan §10 explicitly asked to stop the per-frame re-render.
3. **Apply does not reach all mounted screens (item 3).** Density and radius are stored but never reach real screens: every screen reads the module constants `spacing` / `radius` inside `StyleSheet.create` at module load (for example `screens/appearance/appearance-screen.tsx:573-650`; the plan admits this at `docs/theme-customization-plan.md:40`). Typography is pushed through a module-level global mutated during render (`theme/theme-preference.tsx:363-367`, `theme/typography.ts:118-120`), so it only shows up in components that re-render for another reason. The plan also lists 29 files with fixed `fontSize` / `lineHeight` values that ignore the scale (`docs/theme-customization-plan.md:41`).

## Other observations

- The theme test suite cannot run: `jest.setup.ts` fails under the NativeWind babel transform (`_ReactNativeCSSInterop` referenced in a `jest.mock` factory). Every test-based verification above is blocked until that is fixed. Command used: `npx jest src/theme/theme-preference.test.tsx` from `reactnative-mobile/`.
- `setLiveTypography` mutates module state during render (`theme/theme-preference.tsx:363-367`). This is not concurrent-safe under React 19 (an interrupted render can leave the global ahead of the committed tree).
- The cross-fade effect reads `AccessibilityInfo.isReduceMotionEnabled()` on every color change (`theme/theme-preference.tsx:316`); fine, but this adds an async hop before an instant switch under Reduce Motion.
